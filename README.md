# MeetingRec for iPhone — releases

Public distribution for **MeetingRec for iPhone** (the source code lives in a private repo).

## Install / update via AltStore
Add this **source** in AltStore:

```
https://raw.githubusercontent.com/ktaichi326/MeetingRec-iOS-releases/main/apps.json
```

Then install **MeetingRec** from it. Updates show up in AltStore when a new version is published here. Requires iOS 17+.
The IPA is unsigned; AltStore signs it with your own Apple ID (free accounts: 7-day expiry, refreshed by AltServer).
